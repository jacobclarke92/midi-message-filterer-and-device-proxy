# Midi message filterer / midi device proxy

Got a midi controller that's playing up and performing free jazz all over your DAW?  
Same. This is a simple tool to work around that by acting as a proxy for your midi device and filtering out messages you don't want to see.

It remembers your settings and lets you download a settings file to restore later.

![Example](https://raw.githubusercontent.com/jacobclarke92/midi-message-filterer-and-device-proxy/refs/heads/main/example.png)

I could have built this by hand but thought I'd give vibecoding a bit of a go because I'd rather get back to making music. Did tidy up a bit later when finally bundling it all for release.

[Download from releases](https://github.com/jacobclarke92/midi-message-filterer-and-device-proxy/releases)
